# Manual Playtest Checklist

Automated tests do not replace a real browser and family acceptance test. Record the browser, operating system and date when completing this checklist.

## Core game

- [ ] Open `index.html` directly with the network disconnected.
- [ ] Start and complete a cooperative match.
- [ ] Start and complete a competitive match.
- [ ] Check Cash Builder, Head-to-Head offers, Chaser movement and Final Chase.
- [ ] Confirm question rotation does not repeat a question before the eligible pool is exhausted.
- [ ] Save, reload and resume a match.

## Content and presentation

- [ ] Create, edit, delete, import and export custom questions.
- [ ] Check all difficulty and category choices.
- [ ] Test sound enabled and disabled.
- [ ] Test keyboard navigation and visible focus.
- [ ] Test a narrow/mobile viewport and reduced-motion settings.

## Profiles and records

- [ ] Complete a match and verify profile statistics and achievements.
- [ ] Confirm a completed match is not recorded twice.
- [ ] Reload the browser and confirm local records persist.
- [ ] Test the Family Records reset confirmation.

## Tournaments

- [ ] Create tournaments with 2, 3, 4 and 8 contestants.
- [ ] Verify round-robin fixtures and byes for odd-sized fields.
- [ ] Record results and verify standings update.
- [ ] Verify playoff progression and the final champion.
- [ ] Reload the browser and confirm tournament history persists.

## Desktop launchers

- [ ] Test the Windows launcher and shortcut on Windows.
- [ ] Test the Linux launcher and shortcut on a supported desktop environment.
- [ ] Confirm shortcuts still work after extracting the project to a permanent folder.
